Assignment 5: High(er) voltage and transistors!

In this assignment, I used an IRLZ44N MOSFET transistor to control an LED strip with a capacitive touch sensor. When I touch the coin, the LED strip turns on. When I release it, the LED strip turns off.

1. Schematic

The 1M ohm resistor is connected between Arduino pins 2 and 4 for capacitive sensing. Arduino pin 9 connects to the MOSFET Gate. The Drain connects to the LED strip negative terminal, and the Source connects to GND. The external power supply and Arduino share a common ground.

Gate-to-Source Voltage

Vgs = Vg - Vs

When ON: Vgs = 4.47 - 0 = 4.47V

When OFF: Vgs = 0 - 0 = 0V

The MOSFET turns on when the Gate receives a HIGH signal from the Arduino. When the Gate voltage is 0V, the MOSFET turns off.

Drain-to-Source Voltage

Vds = Vd - Vs

Vds = 0 - 0 = approximately 0V

The voltage across the MOSFET is approximately 0V when it is on.

LED Strip Current

Measured current: approximately 0.01A

0.01A x 1000 = 10mA

This reading is approximate because I used the 10A range on my multimeter.

MOSFET Maximum Current

The IRLZ44N has a maximum continuous drain current rating of 47A at a case temperature of 25 degrees Celsius under specified conditions. According to the IRLZ44N Datasheet .

0.01A < 47A

My approximate measured current is much lower than the MOSFET's absolute maximum current rating.

1M Ohm Resistor

I used a 1M ohm resistor between Arduino pins 2 and 4 for capacitive sensing. This resistor helps detect changes in capacitance when I touch the coin.

R = 1,000,000 ohms

I = V / R

I = 5 / 1,000,000 = 0.000005A = 5 microamps

4. Firmware

I used the CapacitiveSensor library to read the coin sensor. The touch threshold is 1000, based on my Serial Monitor readings. The analogWrite() function controls the LED strip through the MOSFET. 


#include <CapacitiveSensor.h> // Include the touch sensor library

// Create the sensor using D2 (send) and D4 (receive).
CapacitiveSensor touchSensor = CapacitiveSensor(2, 4);

// Set D9 as the LED strip control pin.
const int ledPin = 9;

// Set the touch detection threshold.
const long touchThreshold = 1000;

// Start with the LED strip turned off.
int ledBrightness = 0;

// Run this function once when Arduino starts.
void setup() {
  // Set D9 LOW before enabling the output.
  digitalWrite(ledPin, LOW);

  // Set D9 as an output, initially LOW (0V).
  pinMode(ledPin, OUTPUT);

  // Start serial communication at 9600.
  Serial.begin(9600);

  // Disable automatic sensor calibration during testing.
  touchSensor.set_CS_AutocaL_Millis(0xFFFFFFFF);
}

// Repeat this function continuously.
void loop() {
  // Read the capacitive touch sensor using 30 samples.
  long touchValue = touchSensor.capacitiveSensor(30);

  // Print the sensor reading label.
  Serial.print("Touch value: ");

  // Print the sensor reading.
  Serial.println(touchValue);

  // Check if the foil is being touched.
  if (touchValue > touchThreshold) {
    // Set the LED strip to full brightness.
    ledBrightness = 255;
  } else {
    // Turn the LED strip off.
    ledBrightness = 0;
  }

  // Use PWM to control LED strip brightness.
  analogWrite(ledPin, ledBrightness);

  // Print the brightness label.
  Serial.print("LED brightness: ");

  // Print the current brightness value.
  Serial.println(ledBrightness);

  // Wait 50 milliseconds before the next reading.
  delay(50);
}

Question 3: Here is the datasheet for the L293D chip: https://www.ti.com/product/L293D. Draw a schematic using at least your arduino, this chip, and two motors. Write (pseudo) code that shows how you would move the motors both forward, both back, then one forward one back, and one back then forward.

The L293D allows the Arduino to control two DC motors independently. Changing the HIGH and LOW input signals changes each motor's direction.

Motor Direction Table

Movement D4 D3 D6 D5
Both forward HIGH LOW HIGH LOW
Both backward LOW HIGH LOW HIGH
A forward, B backward HIGH LOW LOW HIGH
A backward, B forward LOW HIGH HIGH LOW

Pseudocode


// Motor A: D4 connects to 1A on L293D.
int motorA1 = 4;

// Motor A: D3 connects to 2A on L293D.
int motorA2 = 3;

// Motor B: D6 connects to 3A on L293D.
int motorB1 = 6;

// Motor B: D5 connects to 4A on L293D.
int motorB2 = 5;

// Run setup once when the Arduino starts.
void setup() {

  // Set Motor A input 1 as output.
  pinMode(motorA1, OUTPUT);

  // Set Motor A input 2 as output.
  pinMode(motorA2, OUTPUT);

  // Set Motor B input 1 as output.
  pinMode(motorB1, OUTPUT);

  // Set Motor B input 2 as output.
  pinMode(motorB2, OUTPUT);

  // Start with Motor A stopped.
  digitalWrite(motorA1, LOW);

  // Keep Motor A's second input LOW.
  digitalWrite(motorA2, LOW);

  // Start with Motor B stopped.
  digitalWrite(motorB1, LOW);

  // Keep Motor B's second input LOW.
  digitalWrite(motorB2, LOW);
}

// Repeat the motor movements continuously.
void loop() {

  // Both motors move forward.
  digitalWrite(motorA1, HIGH);
  digitalWrite(motorA2, LOW);
  digitalWrite(motorB1, HIGH);
  digitalWrite(motorB2, LOW);

  // Run forward for 2 seconds.
  delay(2000);

  // Stop both motors before reversing.
  digitalWrite(motorA1, LOW);
  digitalWrite(motorA2, LOW);
  digitalWrite(motorB1, LOW);
  digitalWrite(motorB2, LOW);

  // Wait 200 milliseconds.
  delay(200);

  // Both motors move backward.
  digitalWrite(motorA1, LOW);
  digitalWrite(motorA2, HIGH);
  digitalWrite(motorB1, LOW);
  digitalWrite(motorB2, HIGH);

  // Run backward for 2 seconds.
  delay(2000);

  // Stop both motors before changing direction.
  digitalWrite(motorA1, LOW);
  digitalWrite(motorA2, LOW);
  digitalWrite(motorB1, LOW);
  digitalWrite(motorB2, LOW);

  // Wait 200 milliseconds.
  delay(200);

  // Motor A moves forward.
  digitalWrite(motorA1, HIGH);
  digitalWrite(motorA2, LOW);

  // Motor B moves backward.
  digitalWrite(motorB1, LOW);
  digitalWrite(motorB2, HIGH);

  // Run for 2 seconds.
  delay(2000);

  // Stop both motors before changing direction.
  digitalWrite(motorA1, LOW);
  digitalWrite(motorA2, LOW);
  digitalWrite(motorB1, LOW);
  digitalWrite(motorB2, LOW);

  // Wait 200 milliseconds.
  delay(200);

  // Motor A moves backward.
  digitalWrite(motorA1, LOW);
  digitalWrite(motorA2, HIGH);

  // Motor B moves forward.
  digitalWrite(motorB1, HIGH);
  digitalWrite(motorB2, LOW);

  // Run for 2 seconds.
  delay(2000);

  // Stop both motors before repeating.
  digitalWrite(motorA1, LOW);
  digitalWrite(motorA2, LOW);
  digitalWrite(motorB1, LOW);
  digitalWrite(motorB2, LOW);

  // Wait 200 milliseconds.
  delay(200);
}
